# Consécration de Mograine

Nine exact-size PNG assets in `png/`, matching the approved Inquisiteur UI family.
`preview.png` shows the composed tooltip and the gauntlets' icon with its frame drawn at 130%.
`contactSheet.png` shows all nine pieces. `generationManifest.json` records built-in imagegen prompts and references;
original selected paintings are retained in `source/`.

See `../monasteryLegendaries/README.md` for rebuild commands, registration metadata and integration notes.
Rebuild: `python localTools/interface/buildMonasteryLegendaryArt.py` from the repository root.
