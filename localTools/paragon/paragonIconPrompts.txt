PARAGON BOARD ICONS - prompts for the image generator
=====================================================

One prompt per icon. Save each result as a square PNG (1024x1024 is what the existing icons use) with
exactly the file name given, in:
    modules/mod-stat-growth/client-assets/source/icons/
Then run:
    python localTools/paragon/buildParagonIcons.py
    python localTools/paragon/buildParagonTree.py
The board uses a stock icon for any of these that is not there yet, so they can be done in any order.

The icon is drawn inside a round socket, so keep the subject in the middle ~70% of the square.

Tiers: Ascension icons are the middle zone, Transcendance the outer zone, Apotheosis the six final
keystones - each should look clearly more powerful than the one before.
